# Academic website: Tasfik Rahman

A static site with no build step: `index.html` + `style.css`.

## Photo
`images/profile.jpg` is the full uncropped photo, resized to 600×600. To change it, replace that file with another square image.

## Deploy to GitHub Pages (tasfik007.github.io)
1. Back up your current site (the repo `tasfik007/tasfik007.github.io`).
2. Replace its contents with the files in this folder: `index.html`, `style.css`, `files/`, `images/`, `.nojekyll`.
3. Commit and push to the default branch. The site updates within a minute or two.

## Keep it current
- Update the CV PDF in `files/` whenever your CV changes.
- Add a news item for each paper, talk or new position.
- Add a Google Scholar link in the sidebar (there's a commented-out placeholder) once you have a profile.
